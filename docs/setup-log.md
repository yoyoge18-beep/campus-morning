## 2026-10-15
- **자동화:** Chrome 없이 매일 돌도록 GitHub Actions 수집(07:30) + Claude 예약 작업 발행(08:40) 구조로 전환.
- **네이버 API:** 개발자센터의 검색 API 신규 신청이 2026.7.31 종료되어 네이버 클라우드 NAVER API HUB로 발급. 결제수단 등록이 필요했음(검색 API는 현재 무료).
- **공개 열람:** claude.ai 저장소(db)는 로그인한 사람만 읽을 수 있어서, 기사 데이터를 사이트 파일(`editions/*.json`)로 옮김. 공유 설정을 '링크가 있는 모든 사용자'로 변경.
- **날짜 오류:** 구글 뉴스가 2026.06.12 기사('리브루' 창업 2관왕)를 10.14로 표시 → 판에서 삭제. 구글에서만 잡힌 기사에 `date_verified: false` 표시를 붙이고, 발행 단계에서 원문 발행일을 확인해 3일보다 오래됐으면 제외하도록 변경.
- **언론사 제한:** 13개 언론사만 싣도록 변경. 1순위 부산일보·국제신문·KNN / 2순위 한국대학신문·조선·중앙·동아·연합뉴스·한겨레·경향·한국일보 / 3순위 아시아경제·아주경제. 수집 단계에서 걸러내고, 사이트는 분야 안에서 언론사 순위 → 최신순으로 정렬. 10.14·10.15 판도 같은 기준으로 다시 정리(각 21건).

## 2026-10-16 수집 범위 고정 · 발행 작업이 수집 실행
- **문제:** 07:30 예약 수집이 GitHub 지연으로 09:34에 돌았고, 08:40 발행이 전날 파일(10.15 14:51 수집)로 판을 만듦. 10.15 오후 경남정보대 셰프 대회 기사(부산일보·한국대학신문·아시아경제·아주경제)와 10.16 09:10 KIT 스타트업 포럼 기사가 빠짐.
- **원인:** 수집 범위가 '실행 시각 − 30시간'이라 실행 시각에 따라 범위가 흔들리고, 예약 지연 시 발행이 옛 파일을 씀.
- **변경:** 수집 범위를 전날 09:00 ~ 당일 09:00으로 고정(`collect.py`). Actions 자동 예약 제거, 09:00 발행 작업이 수집을 직접 실행하고 기다린 뒤 발행. 수집 실패 시 웹 검색 보충 대신 발행 중단 + 알림. 부산일보 대학 섹션은 기사 코드의 시·분까지 비교, 구글 뉴스는 when:2d로 받은 뒤 범위로 거름.
